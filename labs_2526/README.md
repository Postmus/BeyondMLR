# Archived 2025–2026 course website

This folder contains the complete previous website project: its configuration, homepage, seven published labs, the additional unpublished random-effects lab, assignments, datasets and stylesheet. The original lab, assignment and data files retain their contents and relative layout.

The earlier duplicate Week 1 backups have been consolidated into this archive. The corresponding revised materials live in `../labs_2627/`.

From the repository root:

```sh
quarto preview labs_2526
quarto render labs_2526 --to html
```

Rendered files are written to `labs_2526/_site/`. This project is retained for reference and is separate from the planned replacement of the GitHub Pages site with the current edition.
